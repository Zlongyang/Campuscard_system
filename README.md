# 校园卡管理系统
这是一个小型的项目demo，仅供学生练习，距离真实落地还需不断拓展完善
文档中目前只支持存放一个学生信息，后续会完善相关功能

## 编译运行方法
1.  确保你的电脑上安装了 `gcc` 编译器（Windows推荐安装MinGW，配置好环境变量）
2.  下载项目后，双击build.bat运行

## 待拓展功能初级

2.  教师解冻学生卡

## 程序架构介绍

表示层（UI交互）
ui
↓
业务逻辑层（业务规则）
login/admin_op/student_op
↓
公共工具层（通用工具、日期、加密、校验）
utils
↓
数据访问层（持久化读写、内存缓存）
file_io
↓
常量配置层 + 数据模型层（纯结构体、枚举、全局常量）
card_data

## 数据存放data说明
student_card:   卡号 姓名 学号 密码 累计充值 余额 状态
record:         卡号 日期 开始时间 时长(分钟) 上机状态 地点
