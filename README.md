# 校园卡管理系统
这是一个小型的项目demo，仅供学生练习，距离真实落地还需不断拓展完善
文档中目前只支持存放一个学生信息，后续会完善相关功能

## 运行方法

### 方式一：直接运行（推荐，无需安装任何环境）
下载项目后，直接双击 `campuscard.exe` 即可运行。
> 该exe采用静态编译，无需安装MinGW或其他运行环境，在任何Windows电脑上都能直接运行。

### 方式二：自行编译（如需修改源码）
1. 安装 MinGW-w64（只需 gcc，无需 make/cmake 等工具）
   - 下载地址：https://winlibs.com （选择 "GCC with MinGW-w64"，解压即用）
   - 将解压后 `bin` 目录（如 `C:\mingw64\bin`）加入系统环境变量 `PATH`
2. 下载项目后，双击 `build.bat` 即可一键编译并运行
